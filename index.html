S.H.A.D.O.W.

Self-Healing Adaptive Defense & Observation WebAn AI-assisted cybersecurity system concept, in development.

S.H.A.D.O.W. is a conceptual AI-assisted cybersecurity system designed to bring security monitoring, threat analysis, privacy protection, and guided incident response into one unified platform. The goal is to help users understand security threats, identify suspicious activity, receive actionable recommendations, and make informed decisions through an intelligent assistant. Potentially sensitive or disruptive actions should require user approval.

CORE MODULESSHADOW Assistant — security guidance · SHERINGEN EYE — suspicious-link analysis & phishing awareness · SILENT GUARD — Android privacy and device-interaction awareness · SHADOW Core — coordinates findings, evidence & recommendations · Guided Recovery — incident-response and recovery guidance
DESIGN PRINCIPLESEvidence-based threat analysis · Privacy-first monitoring · Human approval for sensitive actions · Transparent recommendations · Documented limits & reproducible results
TECHNOLOGYTo be selected by module requirements. AI integration, backend services, web interfaces & storage are architectural considerations.
PROJECT STATUSConcept / In Development. Planned capabilities only; features will be labeled implemented after code exists and has been tested.

CTF / CRYPTO · PUBLIC REPOSITORY

BLACK BULLS CRYPTO

A story-driven Flask cryptography CTF with 12 progressive chapters, optional hints, and SQLite-backed player progress.

The repository documents encoding and cipher challenges from Base64 and XOR to RSA and AES. Public source uses stored SHA-256 flag hashes; the author solution and local database are excluded.

  • 12 chapter-based cryptography puzzles with three hint tiers.
  • Flask, Flask-SQLAlchemy, SQLite, PyCryptodome, and cryptography.
  • Scoring, achievements, story progression, and a custom dark-fantasy interface.
